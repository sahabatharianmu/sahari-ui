The Sahari "calm pulse" — a soft purple orb with a breathing glow, used sparingly as the brand's one signature motion element.

```jsx
<PulseOrb size="lg" />
```

Use ONLY in: onboarding hero, loading states, booking/payment success confirmation, and empty states. Never as decoration on ordinary content — it's a moment marker, not a pattern. `animated={false}` for a static rendering (e.g. inside a screenshot or print context).
