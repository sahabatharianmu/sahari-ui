# @sahari-ui/storybook

Storybook app for Sahari UI visual QA and component docs.

## Run

```sh
cd sahari-ui
pnpm storybook
```

## Build

```sh
pnpm --filter @sahari-ui/storybook build
```

## Includes

- Component stories
- Light/dark theme sample
- Mobile discovery composition
- Storybook a11y addon

## Rule

Stories should show real Sahari product moments, not generic placeholder UI.
